# 运行环境与算力预算（AutoDL）

> 本文件是所有"要花钱"的决定的事实来源。价格会变，**下单前以 AutoDL 站内实时价为准**。
> 价格快照来源：AutoDL 官方报价抓取（2025-09-19）与第三方比价统计（2026-07，3090/4090/A100/A800 中位数），两者一致。

## 1. 决策摘要

| 角色 | 卡 | 单价 | 理由 |
|---|---|---|---|
| **主力迭代**（编译 + llama-bench + profiling） | **RTX 3080 Ti 12G** | ¥1.14/h | 与 3090 **同为 SM86**（同一套 `mmq-config-ampere.cuh` / 同一 kernel 分支），带宽 912 vs 936 GB/s（差 2.6%），单价低 31% |
| **保底 / 长 context / 大 batch 实验** | RTX 3090 24G | ¥1.66/h | 24G 消除一切显存相关的混淆变量；AutoDL 官方文档自称"性价比首选" |
| **杂活**（下载/上传/写代码/整理结果） | 无卡模式 | ¥0.1/h | 0.5 核 + 2G，**开不了编译**，只用于非 GPU 工作 |
| **§12 跨架构**（各 4~8h） | 2080Ti(SM75) / 4090D(SM89) / A100(SM80) | 0.88 / 1.98 / 3.45 | 同一套 harness 换卡即得对比 |
| **§12 跨后端**（可选，+¥30~50） | MTT S4000（MUSA）/ 昇腾 910B（CANN） | 2.30 / 3.14 | llama.cpp 两个远不成熟的后端 + 国产卡适配岗位素材 |

**明确不选**：T4（¥0.82/h 但带宽 320 GB/s，同样扫描慢 2.9 倍，单位工作量成本 ¥2.40，是 3080Ti 的 2 倍）；Pascal 系（TITAN Xp/1080Ti/P40：无 tensor core，走完全不同的 fallback 路径，结论不可迁移）；3060（SM86 但带宽仅 360 GB/s，单位工作量反而贵）；2080Ti 只作为跨架构的一格，不做主力（SM75 与主结论不同路径）。

其他计费规则（官方文档核实）：
- 按量计费**精确到秒**，关机即停止 GPU 计费；整点扣费一次 + 关机扣费一次。

## 3. 为什么看 ¥/工作量，而不是 ¥/h

`成本 = 单价 × 小时数`，`小时数 ∝ 工作量 / 吞吐`。解码阶段吞吐近似由带宽决定，于是同一套 baseline 扫描的相对成本：

| 卡 | 相对耗时 (936/带宽) | 单价 | **单位工作量成本** |
|---|---|---|---|
| RTX 3080 Ti | 1.03x | 1.14 | **1.17** ✅ |
| RTX 2080Ti | 1.52x | 0.88 | 1.34 ⚠️ 路径不同 |
| RTX 3090 | 1.00x | 1.66 | 1.66 ✅ |
| RTX 4090D | 0.93x | 1.98 | 1.84 |
| RTX 4090 | 0.93x | 2.19 | 2.03 |
| Tesla T4 | 2.93x | 0.82 | **2.40** ❌ |
| TITAN Xp | 1.71x | 0.52 | 0.89（但无 tensor core、路径不同 → 不可用） ❌ |

**prefill 是另一条曲线**：prefill 由算力主导，4090D 的 FP16 算力是 3080Ti 的 2.3 倍（147 vs 70 TFLOPS），单位 prefill 工作量成本 0.86 vs 1.14。
→ 结论：**decode 密集用 3080Ti/3090，prefill 大扫描短开 4090D**。

### 4.1 缺货预案：抢不到 3080Ti 怎么办

3080Ti 只是"最便宜的那张同门 SM86 卡"，**不是必需品**。换卡对本项目损失接近于零，只要守两条纪律：

1. **同一组对照实验（baseline vs patch）必须在同一张卡上跑完**，否则差异里混进硬件变量；
2. **换卡后 baseline 重跑一遍**（或在 `docs/findings.md` 注明"跨卡比较不成立"）。
   llama-bench 每行 jsonl 自带 `gpu_info`，会**自动留痕**，不会静默出错。

同平台内的替代顺序：

| 优先级 | 型号 | 价格 | 说明 |
|---|---|---|---|
| 1 | **RTX 3090 24G** | ¥1.66/h | 同 SM86、带宽更高（936）、24G 消除显存顾虑 → **首选替代** |
| 2 | RTX 4090D / 4090 | ¥1.98 / ¥2.19 | prefill ≈2.3x，墙钟更省；SM89，报告里注明架构 |
| 3 | A5000 24G / A4000 16G | 见站内价 | 同 SM86，可用 |
| ⚠️ | V100-32G | ¥1.98/h | SM70，**只作 §12 跨架构的一格**，不做主力 |
| ✗ | 2080Ti / 3080 x2 / Pascal 系 | — | 2080Ti 是 SM75（结论不迁移）；3080 x2 引入多卡 split 变量 |

同平台找卡手段：算力市场按「地区 + 型号」筛空闲主机；换地区（北京 / 内蒙 / 重庆 / 西北 / 佛山…）；
**迁移实例**（官方 QA：空闲 GPU 不足 → 无卡模式 + 迁移实例）；包年包月可**预留 GPU**（确定日均 >8h 高强度使用才划算，但能锁价 + 免抢）。

换平台备份（**以下为 2026-05 第三方比价文数字，该文有明显营销倾向，务必自行核价**）：

| 平台 | 4090 时租参考 | 备注 |
|---|---|---|
| AutoDL | 1.61（会员/学生折后） | 镜像最全，**高峰期需抢卡**（本项目遇到的实际问题） |
| 恒源云 | 1.32 | 地板价，供应稳定性公开信息少 |
| 智星云 | 1.50 | 声称物理独享 + 一价全含；新用户券以官方为准 |
| 英博云 | 1.99（教育 1.66） | |
| 聚合 / P2P 平台 | 1.30~1.86 | 最便宜但可靠性差，适合短平快实验 |

**比价口径**：只比时租会被隐性费用坑（带宽/存储附加费，第三方称 72% 用户遇过、平均多花 25%）→
用**月总支出**比较。2026 年算力市场整体上涨（第三方引高端卡半年涨幅 ~40%），"更便宜"的空间在收窄。

**本项目的可移植性**：`scripts/` 与 `benchmark/` 全是 bash + 标准库 Python，无平台依赖 ——
换平台只需重建环境、重跑 `smoke.sh`，其余流程不变。

### 4.2 全线无卡时怎么办（3080Ti/3090/4090 都没货）

先别急着换平台，按顺序试：

1. **扫其他型号 + 双卡实例**。常有余量的是：A4000 16G、A5000 24G、**3080 x2**、**2080Ti x2**、V100-32G、L20/A40。
   **双卡实例可以只跑一张卡**：`CUDA_VISIBLE_DEVICES=0`（或 llama.cpp 的 `-dev CUDA0` / `-sm none -mg 0`）→
   等效单卡（计价口径以下单页为准；双卡实例 CPU/内存翻倍，编译反而更快）。
   3080 是 **SM86（与 3090 同代码路径）**，2080Ti 是 SM75。
2. **挂库存监控**：官方弹性部署 API 有地区库存接口（`idle_gpu_num`/`total_gpu_num`，部分说明要求企业认证）；
   社区也有现成监控脚本（自行审查代码与合规性）：
   `github.com/Kenny-Huang-mz/autodl-gpu-availability-monitor`、`github.com/iioSnail/autodl_idle_gpu_monitor`、
   `github.com/Jiayi-Fu/autodl-gpu-monitor`。配合微信/邮件提醒，别手动刷。
3. **把"抢到卡之前"该做的全做完**（见下），这样卡一到就能立刻出数据 —— 抢卡窗口里最贵的是环境搭建和下载。
4. **换平台**：恒源云 / 智星云 / 英博云 / 图灵小镇 / 矩池云 / 聚合平台。用**新用户券先小额时租跑 3 天**
   （验证浮点/带宽/运维），确认后再决定长期用谁。
5. **免费兜底（有边界）**：Kaggle 免费 Notebook（P100 / T4，约 30 GPU-h/周）能编译 llama.cpp CUDA 后端、
   跑 llama-bench 基线，**但做不了 `ncu` profiling** → 只能覆盖 §6~§7，覆盖不了 §8。别拿它当长期方案。
6. 别做：反复开关机刷卡（无卡模式会释放 GPU，等于把卡让给别人）。

**等待期的零 GPU 工作（照做就是进度）**：

| 工作 | 为什么不花 GPU | 产出 |
|---|---|---|
| 本机 WSL 编 llama.cpp **CPU 版**并跑通 harness | 不需要 CUDA | 验证 `run_bench.sh`/`collect_metrics.py` 链路（除 CUDA 特有项） |
| 跑通 `smoke.sh` 的非 GPU 分支 | 同上 | 提前暴露脚本问题 |
| GPTQ/AWQ 算法第一版（小模型 + CPU 校准） | 纯算法 | P3 的地基 |
| mini 平台（网关/扩缩/看板）本地 Docker | 不需要 GPU | P4 整个项目 |
| Triton kernel 正确性开发（用 Kaggle/Colab 免费额度） | 免费额度够用 | P1 的地基 |

**48 小时决策规则**：48h 内抢到 → 继续 AutoDL；48h 没抢到 → 换平台开按量实例先跑 `smoke.sh`；
一周都没卡 → 改叙事：目标架构从 SM86 改成 SM75/SM70（`说明.txt` 原案本来就是 Turing），或把主线切到 P1/P4。

### 4.3 镜像与工具链选择

镜像决定的是**编译器 + CUDA toolkit**，不是"哪个框架新"。三条硬规则：

1. **CUDA 版本 ≤ 宿主驱动支持的上限**（最容易踩的坑）。开机第一件事 `nvidia-smi` 看右上角 `CUDA Version: X.Y`
   —— 那是这台宿主的**驱动上限**，`nvidia-smi` 显示的**不是**镜像里装的 toolkit 版本（官方文档明确说明）。
   例：3080Ti 主机常见驱动 535.104.05 → 上限 CUDA 12.2，选 12.4/12.8 的镜像可能跑不起来（driver too old）。
2. **Ampere 卡要求 CUDA ≥ 11.1**（官方 GPU 选型文档：3060/3080Ti/3090/4090/4090D/A4000/A5000/A40/A100/A800/L20/H20/H800）；
   实际建议 **≥ 11.8，优先 12.x**（llama.cpp / Triton 都更省事）。
3. **优先 Ubuntu 20.04+ 的镜像**：官方老文档写"多数 18.04、少数 20.04"，而 18.04 的 gcc 7.5 编 llama.cpp 容易翻车
   （需要较新的 C++17 编译器；`build.sh` 会打印 gcc 版本，编不过就 `apt install gcc-11 g++-11` 或换镜像）。

参考镜像（以站内实时列表为准）：

| 场景 | 镜像 | 说明 |
|---|---|---|
| **通用首选** | PyTorch **2.5.1 / Python 3.12 / CUDA 12.4** | 现代且兼容面广（需驱动 ≥ 550） |
| 保守稳妥 | PyTorch **2.3.0 / Python 3.12 / CUDA 12.1** | 驱动 ≥ 530 即可 |
| 极简（本项目只用编译器） | **Miniconda conda3 / Python 3.10 / CUDA 11.8** | 官方说明"内置 CUDA 带 .h 头文件"，适合二次编译 |
| 前沿 | PyTorch 2.7/2.8 / CUDA 12.8 | **仅在确认宿主驱动 ≥ 570 时选** |
| ✗ | 任何 CUDA ≤ 11.0 的老镜像（PyTorch 1.1~1.7） | Ampere 卡直接不可用 |

**Nsight（ncu / nsys）通常不在镜像里**，需要自己装 —— 这是 §8 的前置条件：

```bash
which ncu nsys            # 先看有没有
# 没有的话两条路：
#   a) NVIDIA CUDA apt 源的可选包（版本号与镜像 CUDA 对齐，例如 12-4）：
sudo apt-get update && sudo apt-get install -y cuda-nsight-compute-12-4 cuda-nsight-systems-12-4
#   b) 用 CUDA toolkit 的 .run 安装器（AutoDL 官方文档 /docs/cuda/），安装时只勾 Nsight 组件
# 也可以先在镜像市场搜 "nsight" 看有没有人打包好的社区镜像
```

装完**立刻**用 `bash scripts/smoke.sh` 的第 3 项验证 profiling 权限：报 `ERR_NVGPUCTRPERM` 就是驱动限制，
云上未必能解（需要宿主设 `NVreg_RestrictProfilingToAdminUsers=0` 或开工单）——**这是整个 §8 的生死线**。

**换镜像会重置系统盘**（官方操作：关机 → 更多操作 → 更换镜像），所以：
**项目代码与模型一律放数据盘 `/root/autodl-tmp/`，系统盘只放环境。**
选镜像不要纠结版本号：**开机跑 `smoke.sh`，缺什么补什么**；补不动就换镜像，成本是 5 分钟。

| # | 检查 | 失败含义 |
