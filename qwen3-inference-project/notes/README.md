# 每日记录

**格式**（每条必须含数字，不许写"今天研究了 X"这种没有产出的句子）：

```markdown
# YYYY-MM-DD

## 做了什么（命令级）
- 跑了什么命令 / 看了哪个文件

## 结果（数字级）
- 关键数字 + 出自哪个 results/raw 文件

## 结论（一句话）
## 未解决 / 下一步
```

**规则**
1. 每条数字必须能追到 `results/raw/` 的文件名。
2. 当天没有产出数字也要写——但要写清"为什么没产出"（环境问题？卡没抢到？）。
3. 失败的尝试也要记（这是判断力证据，见 `docs/experiments.md §3`）。
